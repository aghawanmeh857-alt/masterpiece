# Coastal environment assets

Downloaded from Sketchfab, licensed CC BY 4.0. Attribution is in ../credits.html.

- palm-tree.glb: low poly Palm tree by lucq22, 1k textures.
  https://sketchfab.com/3d-models/low-poly-palm-tree-10365d785677428291aecc4464bf0f2d
- beach-table.glb: Beach table by Jayson Stauffer, 1k textures.
  https://sketchfab.com/3d-models/beach-table-e559392994e04527b3f5ee35a8c3c418

Copies are scaled/placed in hero/coastal-environment.js; the GLB content is unchanged.
Sand, ocean, sky and celestial objects use native Three.js geometry/shaders.
Day/night toggles update sunlight, moonlight, stars, water color and six real street lights.
Animation respects reduced motion; repeated props share geometry and materials.
