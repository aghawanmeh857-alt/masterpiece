Downloaded GLB with 1k textures; original file is unchanged.
The live scene selects 12 buildings, scales and places them beside/behind CareerHub,
merges tiny pieces by material, reduces gloss and fades emissive windows with night mode.
Roads are built locally in Three.js. Attribution is also in ../credits.html.
