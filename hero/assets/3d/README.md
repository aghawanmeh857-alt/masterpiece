# مجسّمات الجولة المستخدمة

- `furniture/modern-office.glb`: أثاث المكاتب والنباتات التي يستخدمها المشهد.
- `people/formal-boss.glb` و`people/formal-businesswoman.glb`: الشخصيات وحركاتها.
- `environment/`: النخيل والشاطئ وموديلات المدينة المستخدمة أو البديلة.
- بقية الإضافات وموديل مقر الشركة موجودة داخل مجلد `3D/` الرئيسي.

الجولة الفعلية: `hero/userHero.html`. معاينة الإضافات: `3D/preview.html`. أُزيلت فيديوهات ومعاينات التجهيز القديمة والموديلات التي لم يعد المشهد يستخدمها. المصادر والتراخيص محفوظة في `Credits/credits.html` وملفات README التابعة للمجسّمات.
