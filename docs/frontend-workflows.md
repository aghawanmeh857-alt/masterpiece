# مسارات الفرونت إند

كل التفاعلات تعمل خلال الزيارة الحالية باستخدام ذاكرة `app.html`. لا يوجد تخزين دائم أو ربط بقاعدة البيانات. قاعدة Masterpiece مستقلة داخل SQL Server وجاهزة للربط لاحقًا.

## المسارات الحالية

- الدخول والتسجيل التجريبيان يحددان نوع الحساب والخدمة، دون حفظ كلمات المرور.
- المشاريع والوظائف والتدريب: عرض التفاصيل ومرفقات الناشر، ثم التقديم ومتابعة الطلب من الملف الشخصي.
- المفضلة عامة لكل الأقسام. السلة مشتركة وتستبعد الوظائف والمشاريع.
- الدورات والورش: تسجيل مجاني أو دفع تجريبي، ثم دروس وتقدّم وملاحظات واختبارات.
- الفعاليات: تسجيل مجاني أو واجهة دفع تجريبي، ثم متابعة التسجيل من الحساب.
- رسوم التقديم على التدريب منفصلة عن المكافأة التي تدفعها الشركة للمتدرّب.
- الملف الشخصي: المعلومات الشخصية، السيرة والشهادات، الدورات والورش والطلبات والفعاليات. لا توجد باقة مدفوعة أو فرق مشاريع.
- الشركة تنشر وظائفها وتدريباتها وتراجع المتقدمين. الأدمن يدير الدورات والورش والفعاليات والمحتوى.
- ملفات الصور وPDF تبقى في سجل المرفقات بالصفحة المضيفة حتى إعادة التحميل. يُعرض ملف الناشر الأصلي؛ عند غيابه تظهر المعلومة عند الضغط على زر PDF.
- المحادثات محلية؛ الاجتماعات تستخدم Jitsi اختياريًا عند الانضمام.

## المكونات والفحوصات

راجع `docs/PROJECT-STRUCTURE.md` لتوزيع الملفات المشتركة. الفحوصات موجودة في `scripts/check-*`. اختبارات قاعدة البيانات الفعلية اختيارية باستخدام `node scripts/check-masterpiece-db.cjs --integration`، وتُلغى بيانات الاختبار بـROLLBACK.
