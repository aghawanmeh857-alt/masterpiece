# CareerHub — 3D animation

هذه مرحلة التجهيز والمعاينة قبل تعديل الموقع، حسب طلب المستخدم.

- `building/low-poly-skyscrapers.glb`: مبنى Sketchfab محفوظ محليًا.
- `furniture/office-assets.glb`: أثاث وأجهزة مكتبية، نسخة textures 1k.
- `furniture/modern-office.glb`: غرفة مكتبية جاهزة، نسخة textures 1k.
- `people/formal-boss.glb`: شخصية ببدلة مع حركات الوقوف والجلوس والمشي.
- `people/formal-businesswoman.glb`: موظفة بملابس عمل رسمية، rigged/animated.
- `preview/Tour/tour.html`: معاينة مستقلة لمسار الجولة باستخدام Three.js.
- `preview/CareerHub-tour-concept.mp4`: فيديو 48 ثانية، 1280×720، 20 fps.

الشخصيات في المعاينة تستخدم الموديلات الرسمية المحمّلة. المبنى والغرف والأثاث في الفيديو أشكال تصوّرية مؤقتة لتقييم حركة الكاميرا وتوزيع المساحات؛ الموديلات المحمّلة لهذه الأجزاء محفوظة ولم تُدمج بعد. الشخصيات البشرية العامة التي نزلت سابقًا ليست ضمن ملفات المشروع أو الاختيار النهائي.

المسار: الواجهة → المدخل والباب → الاستقبال → Freelance → Academy → Internships → Jobs → Events. الشعار على الواجهة وفوق الباب. الأزرار ولوحة النشاط التي طلب المستخدم حذفها لا تظهر في المعاينة.

لم يتم تعديل hero/userHero.html أو hero/userHero.js أو GSAP أو المكونات المشتركة في هذه المرحلة. التنفيذ بعد مراجعة الفيديو.
